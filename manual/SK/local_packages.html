10. Lokálne balíčky (Shared Libraries / Linker)

10.1 Princíp fungovania (Natívny .pth injektor bez UAC)

Funkcia Lokálne balíčky (Linker) rieši základnú potrebu moderného Python vývojára: ako vyvíjať modul alebo plugin na jednom mieste a okamžite ho používať v ľubovoľnom projekte bez neustáleho kopírovania, buildovania či inštalovania cez pip.

VenvHub Pro nevyžaduje žiadne administrátorské práva (UAC) a nevytvára rizikové zástupcov (NTFS Junctions) na disku. Využíva oficiálny a najstabilnejší štandard Python ekosystému: injektovanie ciest cez venvhub_links.pth priamo v priečinku site-packages cieľového Venvu.

Ako to funguje pod kapotou:

  • Priame zaradenie do sys.path: Pri prelinkovaní zapíše VenvHub Pro absolútnu cestu k vášmu balíčku do súboru site-packages/venvhub_links.pth. Python pri každom štarte súbor automaticky prečíta a okamžite sprístupní vaše moduly.
  • 100% podpora pre IntelliSense (VS Code & Cursor AI): Statické analyzátory (Pylance / Pyright) natívne čítajú .pth súbory z aktívneho prostredia. Vďaka tomu okamžite funguje automatické dopĺňanie kódu, nápovedy, typová kontrola a skok na definíciu (F12) bez varovných hlášok Import could not be resolved.
  • Automatické riešenie závislostí: Ak váš balíček vyžaduje externé knižnice z PyPI (napr. colorama, requests), Linker ich pri zapnutí balíčka ticho a synchrónne doinštaluje cez vybraný inštalátor (Pip alebo UV).
  • Kompletná správa IDE: Do editora sa automaticky prenesú potrebné pluginy, nastavenia, príkazy (Tasks) aj klávesové skratky definované v metadátach balíčka.

10.2 Štruktúra balíčka a predloha local_meta.json

Každý priečinok v archíve lokálnych balíčkov predstavuje samostatný modul a musí obsahovať konfiguračný súbor local_meta.json. Tento súbor riadi správanie balíčka, jeho závislosti a prepojenie s vývojovým prostredím.

Kompletná predloha konfigurácie (Master Template):

{
    "name": "alert",
    "version": "1.0.0",
    "short_description": "Notifikačný systém pre vizuálne a zvukové upozornenia",
    "import_path": "src.logic.alert",
    "requires_local": ["logger_service"],
    "requires_pip": ["colorama>=0.4.6", "requests"],
    "vscode_integration": {
        "extensions": [
            "pkief.material-icon-theme"
        ],
        "settings": {
            "python.analysis.typeCheckingMode": "basic"
        },
        "tasks": [
            {
                "label": "Testovať Alert modul",
                "type": "shell",
                "command": "python -m unittest discover -s tests"
            }
        ],
        "keybindings": [
            {
                "key": "ctrl+shift+a",
                "command": "workbench.action.tasks.runTask",
                "args": "Testovať Alert modul"
            }
        ]
    }
}

Detailné vysvetlenie všetkých parametrov:

Kľúč / Sekcia Typ Význam a funkcia v systéme
name String (povinný) Názov priečinka balíčka na disku a jeho interný identifikátor v aplikácii.
version String Sémantická verzia balíčka (zobrazuje sa v tabuľkách správcu).
short_description String Stručný popis funkcionality zobrazený v okne výberu lokálnych balíčkov.
import_path String (kľúčový) Cieľová importovacia cesta v kóde. Ak vyvíjate modul určený pre vnorenú zložku (napr. src/logic/alert/), sem zadáte "src.logic.alert". Vďaka tomu píšete v hlavnom projekte finálny import from src.logic.alert import send_alert už počas vývoja v Linkeri.
requires_local Array of String Zoznam iných lokálnych balíčkov z vášho archívu, ktoré tento balíček vyžaduje. Linker ich pri zaškrtnutí automaticky rekurzívne pripojí.
requires_pip Array of String Zoznam PyPI závislostí vrátane špecifikácie verzií (napr. "requests>=2.28.0"). Linker ich automaticky nainštaluje a APT subsystém ich ochráni.
vscode_integration.extensions Array of String Zoznam rozšírení pre VS Code a Cursor AI (napr. ikony, lintery), ktoré AptIDELogic automaticky nainštaluje do aktívneho profilu a pri odlinkovaní bezpečne odstráni (Autoremove).
vscode_integration.settings Object (Key-Value) Špecifické konfiguračné kľúče, ktoré sa zapíšu do projektového .vscode/settings.json.
vscode_integration.tasks Array of Object Definície spustiteľných úloh, ktoré sa bezpečne vložia do .vscode/tasks.json.
vscode_integration.keybindings Array of Object Definície klávesových skratiek, ktoré sa pridajú do .vscode/keybindings.json.

10.3 Nastavenie koreňovej cesty

Pred prvým použitím Linkera definujte spoločný priečinok pre vaše zdieľané balíčky:

  1. Otvorte Manager (🖥️) -> záložka Nastavenia.
  2. V sekcii Základné cesty nájdite riadok Lokálne balíčky.
  3. Kliknite na ikonu 📁 a vyberte priečinok (napr. F:\Python_local_packages\linker\), v ktorom má každý balíček svoj vlastný podadresár.

10.4 Prelinkovanie do Venvu

Prepojenie vybraných knižníc s konkrétnym virtuálnym prostredím je otázkou niekoľkých sekúnd:

  1. V Správcovi na záložke Správa Venvs kliknite pravým tlačidlom myši na cieľové prostredie.
  2. Zvoľte možnosť 🔗 Lokálne balíčky.
  3. V tabuľke zaškrtnite moduly, ktoré chcete v projekte používať.
  4. Kliknite na 💾 Uložiť zmeny (Prelinkovať).
Plná orchestrácia na pozadí: Linker zapíše cesty do venvhub_links.pth vo Venve, aktualizuje venvhub.json, ticho doinštaluje chýbajúce PyPI balíčky, nainštaluje IDE rozšírenia do profilu a prepojí VS Code konfiguráciu.

10.5 Integrácia s VS Code a Cursor AI

VenvHub Pro udržiava vývojové prostredia (VS Code aj Cursor AI) v dokonalej synchronizácii s virtuálnym prostredím:

  • Okamžitý Pylance IntelliSense: Cesty zo súboru venvhub_links.pth a zoznam python.analysis.extraPaths v settings.json zaručujú, že editor okamžite pozná všetky vaše typy, funkcie a docstringy.
  • Autonómny APT IDE Subsystém: Rozšírenia vyžiadané cez vscode_integration.extensions sú automaticky nainštalované priamo do dátového priečinka aktívneho profilu.
  • Ochrana používateľských úprav (Brutal Check & Tracker): Všetky vložené úlohy a skratky sú evidované v súbore .vscode/venvhub_tracker.json. Linker pri zmenách manipuluje výhradne so svojimi záznamami a nikdy nezmaže vaše vlastné úlohy či konfigurácie.

10.6 Pribalenie do PyInstallera (.EXE)

Pri kompilácii projektu do finálneho .exe programu cez záložku PyInstaller Builder nemusíte pre lokálne balíčky nastavovať žiadne špeciálne parametre.

VenvHub Auto-Injector: Pred spustením PyInstallera analyzátor automaticky prečíta aktívne prelinkovania a vygeneruje:
  • Parameter --paths pre každý balíček (PyInstaller nájde kompletný zdrojový kód bez nutnosti manuálneho zadávania Hidden Imports).
  • Parameter --add-data pre automatické pribalenie všetkých vnútorných obrázkov, šablón, JSON súborov a assetov z vašich lokálnych balíčkov.

10.7 Samooprava ciest na USB kľúči (Portable režim)

Okamžitá tichá oprava písmena disku: Pri spustení aplikácie na inom počítači VenvHub Pro automaticky deteguje zmenu diskového písmena (napr. z E:\ na F:\) a v zlomku sekundy opraví cesty vo venvhub_links.pth a venvhub.json vo všetkých prostrediach. Operácia nevyžaduje administrátorské práva a prebehne úplne bez zásahu používateľa.

10.8 Sieťové disky (NAS a zdieľané zložky)

✅ Plná podpora pre UNC a namapované disky: Archív lokálnych balíčkov môže byť umiestnený na lokálnom disku, sieťovom úložisku (NAS) aj v cloudovom synchronizačnom priečinku. Natívny systém .pth zápisu podporuje štandardné Windows cesty (Z:\...) aj sieťové UNC formáty (\\Server\Share\...).

10.9 Životný cyklus: Vývoj v Linkeri ➡️ Copy & Paste do projektu

VenvHub Pro umožňuje unikátny pracovný postup: balíček vyvíjate ako externý modul s plnou podporou našepkávania, a po dokončení ho iba skopírujete do štruktúry projektu bez nutnosti prepisovať akýkoľvek import v kóde.

1. Štruktúra dvoch variantov balíčka:

Varianta A: Priamy balíček (Flat)

Vhodné pre jednoduché utility a nástroje (import priamo pod názvom balíčka).

📁 archiv_balickov/
└── 📁 alert/
    ├── local_meta.json
    ├── __init__.py
    └── core.py

Import v projekte:
from alert import send_alert

Cieľ v projekte po skončení:
MojProjekt/alert/ (vedľa main.py)

Varianta B: Vnorené balíčky (Hierarchické)

Vhodné pre moduly určené do vnorených zložiek (napr. src/logic/alert).

📁 archiv_balickov/
└── 📁 alert/
    ├── local_meta.json
    └── 📁 src/
        └── 📁 logic/
            └── 📁 alert/
                ├── __init__.py
                └── core.py

Import v projekte:
from src.logic.alert import send_alert

Cieľ v projekte po skončení:
MojProjekt/src/logic/alert/

2. Postup krok za krokom (Praktický príklad):

Krok 1: Vývoj v Linkeri

  1. Vytvorte balíček podľa Varianty B v archíve lokálnych balíčkov.
  2. V local_meta.json nastavte "import_path": "src.logic.alert".
  3. Vo VenvHube otvorte Lokálne balíčky a zaškrtnite alert -> kliknite na Uložiť zmeny (Prelinkovať).
  4. V hlavnom projekte (kde zložka src/logic/alert ešte vôbec neexistuje) vytvorte main.py: 
    from src.logic.alert import send_alert

if __name__ == "__main__":
    send_alert("Systém beží cez Linker!")
  5. Vo VS Code funguje 100% našepkávanie pre send_alert a v termináli kód bezchybne zbehne.

Krok 2: Presun do produkčného projektu (Copy & Paste)

  1. Skopírujte zložku src z Linkera priamo do priečinka vášho projektu: 
    MojProjekt/
├── main.py
└── src/
    └── logic/
        └── alert/
            ├── __init__.py
            └── core.py
  2. Vo VenvHube otvorte Lokálne balíčky, odškrtnite balíček alert a uložte zmeny (odlinkovanie).
  3. Spustite main.py vo VS Code termináli:
    👉 Kód zbehne identicky a bez nutnosti upravovať jediný riadok importov v celom projekte.
