About & Features

📁 Decoupled Architecture

No more cluttered code! VenvHub Pro physically separates your source code from virtual environments. Your projects remain clean, while all Venvs are centrally managed in a dedicated Venv Hub directory. If you delete a Venv, your source code stays safe.

💻 VS Code Integration & Meta-Sync

Open VS Code and IntelliSense works immediately. VenvHub synchronizes settings.json and assigns the proper Venv. Through the Meta-Sync feature, it also reads local_meta.json and automatically injects predefined VS Code Tasks and keybindings directly into the project.

📦 Dual-Scan Pip & UV Autopilot

An extremely fast package manager using parallel scanning to detect outdated libraries. Revolutionary feature: When using the uv installer, VenvHub can perform a deep inspection (Check) after updates and automatically resolve dependency conflicts (Auto-Fix) by precisely downgrading affected packages.

🐑 Smart Cloning Engine

Cloning a Venv does not create blind copies with broken absolute paths. It executes a 5-step reproductive reconstruction: discovers dependencies, creates a clean Venv, reinstalls all packages including editable ones (pip -e), and migrates bootstrap files for local packages.

🧳 Portability Protection

VenvHub accurately distinguishes between System and Embed (Local) Python. If you transfer the application on a USB drive to another PC: Embed environments automatically repair themselves thanks to Auto-Healing and run anywhere. System environments are detected and blocked based on Hardware ID signatures, protecting your projects from destructive crashes due to missing C-libraries on an external PC.

⚡ Ephemeral Execution Engine & Kill Tree

Running scripts via temporary .bat files prevents issues with spaces in file paths. The internal Process Registry tracks all PIDs including child processes, executing a clean Kill Tree across the entire process family upon termination.

🔄 Venv Orchestrator & Watchdog

Group Venvs (Frontend, Backend, DB) into Containers. VenvHub launches them in exact sequence using timers and signal "Hooks" to guarantee startup order. The Watchdog monitors process PIDs and intelligently restarts (Respawns) them up to 3 times in case of a crash.

🛠 PyInstaller & Auto-Injector

Visual builder for .exe files. It not only bundles the uv.exe installer and generates a "Birth Certificate" (JSON metadata) with the Python version, but its Auto-Injector also reads linked local packages and dynamically injects their source code and assets into the build.

🐍 Local Embeddable Runtimes

Download "Local" Python versions from ZIP archives without installing them to Windows (no Registry or PATH modifications). VenvHub automatically "hacks" and patches them (installs Pip, unlocks site-packages in the ._pth file) to make them behave as full-fledged installations.

🛡️ Isolated VS Code Profiles (Sandbox)

Extension clutter? VenvHub enables the creation of fully isolated user profiles for VS Code (via --user-data-dir). Each profile maintains its own separate settings and plugins. The built-in synchronizer can even clone your system environment directly into a portable directory with a single click.

🎨 Dual-Theme & AI Modding

Modern UI built on a robust bridge for PyQt6/PySide6, running fully asynchronously (non-blocking during installations). Includes built-in and custom QSS skin systems. Have an AI recolor your theme and import it right back into the app with a single click!

📜 "Birth Certificate" Generator

Every virtual environment automatically generates and maintains its own Birth Certificate (JSON). It documents the Python version, source paths, and exact list of installed packages in real time. When compiled into an .exe, this manifest is hard-bundled with the application, ensuring you always know the exact "DNA" it was built from.
