Features & Capabilities

📁 Separated Architecture

No more mess in your source code! VenvHub Pro physically separates your source code from virtual environments. Your projects remain clean while all Venvs are centrally managed in a dedicated Venv Hub directory. If you delete a Venv, your code stays safe.

💻 VS Code Integration & Meta-Sync

Open VS Code and IntelliSense works instantly. VenvHub quietly syncs settings.json and assigns the Venv. Via Meta-Sync, it reads local_meta.json and automatically injects pre-defined VS Code Tasks and Keybindings directly into your project.

📦 Dual-Scan Pip & UV Autopilot

Ultra-fast package manager using parallel scanning for outdated libraries. Key feature: When using the uv installer, VenvHub performs a deep check and automatically resolves dependency conflicts (Auto-Fix) by precisely downgrading broken packages.

🐑 Smart Cloning Engine

Cloning a Venv doesn't create blind copies with hardcoded broken paths. It executes a 5-step reproduction reconstruction: freezes dependencies, builds a clean Venv, re-installs packages including editables (pip -e), and transfers bootstrap files for local packages.

🔍 Smart Diagnostics & HW Protection

VenvHub accurately distinguishes between System and Embed (Local) Python. If you transfer the application on a USB drive to another PC: Embed environments automatically repair themselves thanks to Auto-Healing and run anywhere. System environments are detected and blocked by the system based on Hardware ID signatures, protecting your projects from destructive crashes due to missing C-libraries on an external PC.

⚡ Temporary Execution Engine & Kill Tree

Script execution via temporary .bat files prevents issues with paths containing spaces. The internal Process Registry tracks all PIDs including subprocesses and performs a clean Kill Tree on execution stop.

🔄 Venv Orchestrator & Watchdog

Group Venvs (Frontend, Backend, DB) into Containers. VenvHub launches them in precise order using timers and signal Anchors (Hooks) to guarantee startup. The Watchdog monitors process PIDs and automatically respawns crashed processes up to 3 times.

🛠 PyInstaller & Auto-Injector

Visual .exe builder. It bundles the uv.exe installer, generates a JSON "Birth Certificate" with runtime metadata, and uses the Auto-Injector to dynamically embed linked local packages and assets directly into the build.

🐍 Local Embeddable Runtimes

Download "Local" Python runtimes from ZIP archives without Windows installation (zero registry or PATH changes). VenvHub automatically patches them (installs Pip, unlocks site-packages in ._pth) to behave as full installations.

🧳 USB Portability & Hardware Protection

Coding on a USB stick? If the drive letter changes on another PC, Venv Validator automatically fixes all paths. Hardware Protection: A system Listener tracks Hardware ID hashes and prevents running incompatible system Venvs on foreign machines.

🎨 Dual-Theme & AI Modding

Modern UI built on a robust PyQt6/PySide6 bridge running fully asynchronously. Includes built-in and user QSS skins. Generate custom themes using AI and import them into the application with a single click!
