About the Program & Features

📁 Decoupled Architecture

No more cluttered project trees! VenvHub Pro physically isolates your source code from virtual environments. Your repositories stay clean while all venvs are managed centrally in a dedicated Venv Hub folder. Deleting a venv never endangers your code.

💻 VS Code Integration & Meta-Sync

Launch VS Code with instant IntelliSense support. VenvHub synchronizes settings.json and binds the environment. Via Meta-Sync, it reads local_meta.json and automatically provisions tasks, debuggers, and shortcuts into your workspace.

📦 Dual-Scan Pip & UV Autopilot

Blazing fast package management powered by parallel outdated checks. Key Innovation: When using the uv engine, VenvHub runs deep dependency consistency checks and executes Auto-Fix downgrades to resolve conflicting packages automatically.

🐑 Smart Cloning Engine

Cloning never creates broken absolute-path copies. It executes a 5-step reproduction process: inspects dependencies, creates a clean venv, reinstalls all packages including editable ones (pip -e), and relocates local package bootstrap files.

🧳 Portability Safeguards

Differentiates between System and Local Embed runtimes. Portable drives run smoothly anywhere thanks to Auto-Healing. System-bound environments are verified against hardware signatures to prevent crashes caused by missing binary DLLs on foreign machines.

⚡ Execution Engine & Kill Tree

Launches scripts through temporary .bat wrappers to eliminate whitespace path errors. The internal Process Registry tracks all child PIDs and guarantees a clean, recursive Kill Tree termination upon shutdown.

🔄 Venv Orchestrator & Watchdog

Group multi-tier services (Frontend, Backend, DB) into Containers. VenvHub boots them in sequence using timers and signal hooks. The Watchdog monitors live PIDs and provides automatic respawn (up to 3 times) on unhandled crashes.

🛠 PyInstaller & Auto-Injector

Visual .exe builder. Bundles the standalone uv.exe installer and outputs complete metadata manifests. With the Auto-Injector, linked editable packages and external static assets are automatically detected and bundled into the build.

🐍 Local Embeddable Runtimes

Download portable Python ZIP archives without requiring Windows installer privileges or altering PATH. VenvHub automatically bootstraps pip and unlocks site-packages within the ._pth configuration to make them fully functional runtimes.

🛡️ Isolated VS Code Profiles (Sandbox)

Extension clutter? Launch sandboxed VS Code instances via --user-data-dir. Each profile maintains isolated extensions and keybindings. The integrated cloner can migrate your system configuration into a portable folder with one click.

🎨 Dual-Theme & AI Modding

Responsive PyQt6/PySide6 user interface operating fully asynchronously during background package tasks. Features prebuilt and custom QSS themes. Export styles to AI for color restyling and import them back instantly.

📜 Runtime Manifests

Every environment maintains an immutable JSON manifest tracking exact interpreter revisions, origin paths, and package freezes. When compiling binaries, this specification is bundled permanently into the binary distribution.
