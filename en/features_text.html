Feature Modules & Roadmap

Overview of key VenvHub Pro components and implementation timeline for upcoming releases.

Next-Gen Interface

VenvHub Manager & Context Menu

The centralized manager window showcasing the new right-click context menu on a selected environment. It serves as the primary gateway to upcoming modules: + Dependency Tree, + Security Audit, and + Snapshot Management (Rollback).

Planned from Version 2.6.07

Package Dependency Tree

Interactive tree visualization of package dependencies within the environment. Allows you to instantly trace library hierarchies, inspect versions, and resolve dependency conflicts.

Planned in Version 2.6.09

Package Security Audit

Built-in security scanner that cross-references installed libraries with public vulnerability databases (CVE), flagging insecure or vulnerable packages with clear severity ratings.

Planned in Version 2.6.09

Snapshot Management & Rollback

Create restore points of your virtual environment's full package state. Enables instant one-click Rollback to a working state if an installation fails or breaks compatibility.
